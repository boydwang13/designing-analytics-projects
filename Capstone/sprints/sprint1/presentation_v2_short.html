* How Matching Works (Profile -> Edge Behavior)

  • Each employee is assigned one profile in mock_data_nodes.csv: hub / broker / island / balanced.
  • Edges are then generated in mock_data_edges.csv based on profile-specific rules.
ProfileEdge behavior
HubModerate outgoing ties; often receives many incoming ties.
BrokerFewer Hard ties; more Soft ties; often cross-team bridges.
IslandVery few outgoing ties (sometimes zero); often weaker frequencies.
BalancedMid-level Hard and Soft ties.

**** Sandbox selection logic

  1. Start with random sampling (fixed seed, repeatable).
  2. If edges are too sparse, add highly connected nodes (top sources/targets).

So it is not pure random. It is random-first, then connectivity-based boosting.

How to Read sprint1_topology_sandbox.png

  • Node size = incoming links (in-degree).
  • Node color: red = higher in-degree, blue = lower in-degree.
  • Edge color = interaction frequency category:
    • Daily = dark red
    • Weekly = orange
    • Monthly = light blue
    • Rarely = dark blue
  • Edge thickness = interaction strength from frequency.
